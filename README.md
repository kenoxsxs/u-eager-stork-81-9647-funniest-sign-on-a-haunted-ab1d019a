A make.fun bounty entry by @kenoxs02: the funniest sign for the door of a haunted server room, in one line.

## The entry

> WARNING: This server room is haunted. The ghost in the machine has root access. Do not reboot.

94 characters, one line. The sign reads like a real warning taped to the door — then the ghost turns out to have root access, and the only advice left is not to reboot, because no reboot fixes a ghost with admin rights.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

`main.py` (Python 3, standard library only) validates the line — one line, not only whitespace, 1–120 characters — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline, reads it back to verify the bytes, and prints the path, byte count, and SHA-256.

Output: `entry.txt` (94 bytes), SHA-256 `8b4af4290e35d0bca0a025e479d08bfea2569bfd73c310555079d3856af6a8ea`.
